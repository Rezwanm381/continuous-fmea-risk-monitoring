# Data rights and public-data strategy

## Status

| Field | Value |
|---|---|
| Dataset | NASA C-MAPSS FD001 |
| Source provenance | `PUBLIC_VERIFIED` |
| Source record license | Not specified |
| Redistribution | `VERIFY_BEFORE_PUBLICATION` |
| Raw-data public-candidate status | Excluded |
| Row/asset-level derivatives | Excluded pending Module 8 |

Public accessibility is not treated as permission to redistribute.

## Source and independent acquisition

Obtain the Turbofan Engine Degradation Simulation Data Set from the official NASA Prognostics Center of Excellence repository. The project records the official landing pages, download URL, citation, archive hashes, and inner-file hashes in [data/README.md](../data/README.md).

The workflow expects only `train_FD001.txt`, `test_FD001.txt`, `RUL_FD001.txt`, and `readme.txt`. It does not require a raw-data copy inside the source candidate.

## Private cache

The local default cache is:

```text
../05_OUTPUTS/private_data_cache/FD001
```

It can be overridden with `CMAPSS_DATA_DIR`. The cache is runtime material, not repository content. Hash validation occurs before modeling.

## Derived artifacts

Row-level predictions and asset-level event tables reproduce substantial structure from official trajectories and final-RUL-derived labels. They remain internal even though they were generated by portfolio code. Aggregate metrics and figures may become public candidates only after Module 8 reviews rights, attribution, privacy, path hygiene, and claim context artifact by artifact.

## Module 8 gate

No public package may include raw NASA files, extracted archives, row-level predictions, asset-level event tables, validation scratch mirrors, or private caches unless explicit approval and rights evidence are recorded. A clean allowlist—not a broad copy of the development workspace—must define the export.
