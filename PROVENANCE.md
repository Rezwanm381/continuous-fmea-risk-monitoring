# Public provenance

The current implementation is a `NEW_PORTFOLIO_REBUILD` derived from graduate coursework. Its source code, tests, documentation, engineering scenario, and decision-support structure were newly created for the portfolio rebuild.

Historical coursework is preserved separately as private provenance. The historical predictive implementation was classified `INVALID_FOR_PREDICTIVE_EVIDENCE`; its code, data, scores, and claims are not represented as the public implementation.

The rebuilt predictive layer uses NASA C-MAPSS FD001, a simulated benchmark attributed in `CITATION.md`. Public access is not treated as redistribution permission. Raw, row-level, and asset-level records remain outside the interim public allowlist, and NASA-derived figures remain held except for the data-independent validation/leakage schematic.

This project does not claim NASA, IEC, ISO, instructor, course-material, or historical-source authorship or endorsement. It is an individual technical portfolio prototype, not a certified or deployed safety system.
